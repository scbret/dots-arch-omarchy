# dots-arch-omarchy

## Only for Arch - Omarchy installs

- contains dotfiles for linking with stow
- do not use stow with hypr folder - it's a backup in case of changes from Omarchy
- `omarchy-plugins/` holds personal Omarchy shell plugins (`steve.ai-usage`, `steve.spotify`) — link them directly into `~/.config/omarchy/plugins/` rather than via stow (see [omarchy-plugins/README.md](omarchy-plugins/README.md))
